# TZGRO v3 設計定案單：擴散經營版

> 狀態：**待委託人訂案**。訂案前不改正式遊戲；本 PR 只新增設計文件與獨立的數值原型。
> 試玩：`npm run dev` 後開 <http://127.0.0.1:8766/prototype/v3/index.html>

## 1. 結論

把遊戲從「每週選卡、線性加成」改成類似瘟疫公司的**擴散競賽**：客人像口碑一樣擴散，對手同步搶市場，現金跑道是另一條倒數。一局 30–45 分鐘，從 2019 年走到 2025 年底。經營原則只在揭曉與結局出現，遊戲進行中不說教。

## 2. 為什麼要改（現行版的問題）

| 問題 | 現象 | v3 的處理 |
|---|---|---|
| 營收沒有複利 | 每週營收＝固定基數 × 一串加成，沒有「起飛」 | 熟客帶新客的擴散公式，成長有複利 |
| 事件有標準答案 | 五種事件都是「先修正條件」最安全 | 同一事件的對錯取決於當下產能、現金、查證 |
| 沒有對手 | 唯一壓力是營收目標 | 對手市占條＋現金跑道，兩條倒數 |
| 選卡同質化 | 選品／粉專／熟客幾乎週週選 | 常態動作交給能力樹，負責人每年指派一次 |
| 一局太長 | 120 週 × 3 分鐘，全破約 6 小時 | 84 個月 × 20 秒，加決策約 30–45 分鐘 |

## 3. 已定案（委託人 2026-10-20）

- 玩家：公司員工／主管培訓
- 一局 30–45 分鐘，一局走完 2019 → 2025，七章變成七個年度
- 借鑑：擴散版圖、能力樹＋點數、對手壓力條、多開局與難度
- 對手：競爭品牌市占＋現金跑道，兩條都要
- 卡牌：保留「派誰做」，改成每年指派一次負責人
- 學習：局中不說教，揭曉時一句原則，結局給診斷報告
- 視覺：粉彩房間＋Q 版方塊角色；成長時房間一間間拼上去，旁邊配市場小地圖
- 順序：先做玩法骨架，再換皮

## 4. 核心循環

```
每月自動推進（1x＝20 秒，可 2x／4x、可暫停）
  觸及 ─→ 詢問 ─→ 成交 ─→ 熟客 ─┐
   ↑  粉專／直播／短影音／廣告      │ 熟客口碑帶來新的觸及（複利）
   └───────────────────────────┘
  同時：對手從潛在客人中搶人；訂單超過出貨產能 → 口碑與士氣下滑
  每月冒出金色泡泡 → 點擊收成口碑點 → 解鎖能力樹
  事件／真實新聞 → 暫停等老闆決策 → 揭曉結果＋一句原則
  每年初：指派三位負責人、看年度目標
```

## 5. 系統規格（原型已實作，`public/prototype/v3/engine.js`）

**市場版圖**：台灣北部、台灣中南部、香港、新加坡、日本，各有潛在客人數。後四區要用能力樹開拓；對手在未開拓的地區照樣成長，晚開拓就會先被拿走。

**擴散公式**（每區每月）：新詢問＝潛在客人 ×（自然觸及＋口碑率）＋廣告帶來的詢問。口碑率與熟客占比、口碑分數成正比。詢問依轉換率成交，成交客人依服務品質轉為熟客。廣告成本隨市場飽和遞增。

**兩條倒數**
- 對手市占：對手的獲客率逐月提高；你的差異化能力（精品、品質、課程）會降低它在你已開拓市場的獲客。**對手拿下 60% → 品類被定義，遊戲結束。**
- 現金跑道：現金 ÷ 近三個月平均月虧損。**現金低於零 → 破產。**

**產能**：出貨產能＝人數 × 每人產能 × 士氣 × 流程能力。訂單超過產能時，口碑與士氣每月下滑。辦公室依年份開放：3 → 6 → 12 → 24 → 40 席。

**能力樹**（口碑點＋現金，部分能力依年份開放）

| 商品 | 通路 | 組織 |
|---|---|---|
| 精選主打 → 品質檢查制度 | 粉專（開局即有） | 出貨流程 → 倉儲外包 |
| 精品線（2020） | 直播（2020） | 授權與合約 |
| 水晶療癒線（2024） | 官網電商（2020，開拓中南部） | HR 與培訓制度（2023） |
| 線上知識課程（2024） | 香港代理（2021，抽成 25%） | 財務治理（2024） |
| | 短影音（2022） | 併購互補公司（2025） |
| | 海外電商（2023）→ 日本跨境（2024） | 上市申請（2025） |

整棵樹 139 點，好的打法一局約拿到 140 點左右，所以順序與取捨很重要（模擬中，把點數花在水晶與課程的打法，就湊不出上市申請）。

**負責人**：每年初指派商品、通路、組織三位負責人；能力影響該部門效果；一人兼兩職效率 ×0.8；從缺效率最低。

**事件**（約每 4–5 個月一次，對錯看情境）

| 事件 | 決定對錯的條件 | 原則 |
|---|---|---|
| 企業禮品急單 | 產能餘裕 ≥ 15% 才該全接 | 接單前先看產能餘裕，不是先看金額 |
| 供應商限時報價 | 花 1 點查證才看得到條件 | 低價背後的條件，要查證才知道 |
| 平台大促 | 現金跑道 < 4 個月才該參加 | 折扣買到的是這個月，不是熟客 |
| 網紅業配 | 口碑 ≥ 60 且產能餘裕 ≥ 20% | 曝光要接得住 |
| 對手挖角 | 看負責人能力高低 | 關鍵人才的成本要跟成果一起算 |
| 代理私下降價 | 有沒有「授權與合約」 | 合約是出事時的工具 |

**真實新聞**（照年份出現，選擇會影響後續數月）：COVID-19 大流行、Apple ATT、Reels 擴展、聯準會升息、花蓮強震。

**開局 × 難度**：標準創業（500 萬、3 人）、網紅起家（200 萬、口碑強、出貨弱）、代工轉品牌（1,000 萬、5 人、品牌弱）；輕鬆／標準／困難調整對手成長速度與事件風險。

**結局**：成功上市（有上市申請、年營收 ≥ 2.5 億、獲利、士氣 ≥ 45）、區域品牌（年營收 ≥ 8,000 萬）、小而美工作室、現金燒完、品類被對手定義。

**結局診斷**（七項，每項一個指標＋一句原則）：現金跑道最低點、廣告獲客成本 vs 客人價值、產能超載月數、採購前查證、對手最高市占、年度目標達成數、事件判斷符合情境的比例。

## 6. 模擬驗證（`node test/v3-strategies.cjs`，標準難度、同一個種子）

三種模擬玩家：**不作為**（不點能力、不投放、不招人）、**平衡**（看產能招人、跑道夠才投放、會查證）、**猛衝**（每月固定 150 萬廣告、不顧產能）。

| 開局 | 打法 | 結局 | 結束於 | 年營收（百萬） | 對手最高市占 |
|---|---|---|---|---|---|
| 標準創業 | 不作為 | 品類被對手定義 | 2024-10 | 3 → 6 → 8 → 10 → 11 | 60% |
| 標準創業 | 平衡 | 成功上市 | 2025-12 | 25 → 55 → 110 → 155 → 226 → 293 → 377 | 53% |
| 標準創業 | 猛衝 | 現金燒完 | 2019-05 | — | 4% |
| 網紅起家 | 不作為 | 品類被對手定義 | 2023-12 | 10 → 8 → 8 → 8 | 60% |
| 網紅起家 | 平衡 | 成功上市 | 2025-12 | 21 → 40 → 55 → 103 → 165 → 219 → 290 | 58% |
| 網紅起家 | 猛衝 | 現金燒完 | 2019-02 | — | 3% |
| 代工轉品牌 | 不作為 | 品類被對手定義 | 2024-09 | 2 → 3 → 4 → 5 → 5 | 60% |
| 代工轉品牌 | 平衡 | 成功上市 | 2025-12 | 28 → 52 → 119 → 158 → 229 → 293 → 398 | 50% |
| 代工轉品牌 | 猛衝 | 現金燒完 | 2019-11 | — | 8% |

`npm test` 會檢查這些承諾：同種子結果相同、不作為會輸、猛衝會破產、平衡打法能上市、年營收逐年上升、急單好壞取決於產能、查證會揭露條件。困難難度下，「網紅起家」的平衡打法也可能被對手定義品類。

## 7. 待委託人決定

1. **原型手感**：每月 20 秒、泡泡停留 8 秒，節奏可以嗎？
2. **舊版七章遊戲**：v3 完成後取代，還是保留並存？
3. **員工深度**：原型只有「三位負責人＋人數」。舊版的隱藏特質、考核、四週改善計畫、追問員工，是主管培訓很有價值的部分；建議改成事件與負責人能力搬回 v3。
4. **視覺換皮的時機**：玩法訂案後，再做粉彩房間＋Q 版角色。

## 8. 未驗證的假設

- 所有數值（客單價 18,000、毛利結構、對手速度、廣告成本）都是遊戲參數，未用公司實際營運資料校準。
- 模擬玩家是規則寫死的；真人的節奏與決策品質沒有測過，需要實際試玩。
- 「一局 30–45 分鐘」是以 1x 速度加上事件估算，尚未實測。

## 9. 訂案後的實作分期

1. 玩法骨架移入正式遊戲：存檔、教學、員工深度、事件文本擴充
2. 視覺換皮：粉彩房間、Q 版角色、房間拼接、泡泡從員工頭上冒出
3. 平衡調整：依真人試玩紀錄調整數值；需要時用公司資料校準
