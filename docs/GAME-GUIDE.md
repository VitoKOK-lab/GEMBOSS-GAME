## 開始遊戲

目前預覽：http://127.0.0.1:8766/tzgro-card-tycoon.html

執行「啟動遊戲.command」（需要 Python 3）；或在 repo 根目錄執行：

`npm run dev`（等同 `python3 -m http.server 8766 --bind 127.0.0.1 -d public`）

再用瀏覽器開啟上述網址。請保留 public/ 內 assets 資料夾與 HTML 的相對位置。

3D 辦公室透過 Three.js CDN 載入，需要網路。遊戲本身不連接真實營運資料。

## 世界脈動（新版）

公司主畫面的跑馬燈會輪播客人留言、模擬市場訊號與當週重大新聞。點擊「世界脈動」可查看需求、廣告效率、直播／短影音觸及、熟客回購與物流成本狀態。

重大歷史新聞依遊戲年份出現，並暫停一週等候老闆決策。選擇的應對會形成數週市場波動，影響後續週的模擬營收；決策紀錄會保留來源連結。

真實新聞與遊戲推演明確分開。新聞固定整理自官方資料，不是即時新聞串流；客人留言和市場脈動是虛構的遊戲訊息，效果數值也是情境假設。

## 巡視同事與分階段辦公室（新版）

一開始是 1F 起步辦公室、3 個座位；公司成長後可以付費擴編一樓到 6 席，再擴大到 12 席。擴張前會先顯示搬遷整備費與每月場地費。點 3D 場景中的員工名牌或員工頭像，即可查看目前任務、星期與時段；可追問進度、卡關和士氣。對話會根據當前角色、週進度、負荷與士氣生成情境式回報。此版本為遊戲內模擬對話，尚未串接 AI API。打開員工回報時，背景工作動畫持續；遊戲時間暫停。

## 上下班與士氣（新版）

一週三分鐘切成五個壓縮工作日；週一至週五每天 10:00 到 19:00。主畫面顯示星期與模擬時間。員工會在 10:00 從門口進入、顯示早安打卡，再到工位工作；19:00 顯示下班告別並離場。重要事件視窗暫停當下班次，跳過時間仍會停在事件決策。每週回顧記錄五天出勤。個人負荷偏高會拉低士氣；士氣影響該員工的工作效率與工作動作速度。團隊總士氣與個別士氣可在主畫面／員工頁查看，並列入週報。

## 玩法

2019 年、3 人、500 萬起步。週初選 0–3 張不同卡牌、指派負責人；三分鐘自動工作，任何決策視窗會暫停。跳過時間仍停在事件。每四週產生月報。

事件可以追問、查文件、付費委託下週查核。員工陳述不保證準確，底層事件事實在產生時固定。

週末逐張揭牌，查看財務與決策成果，再安排下一週。

招募產生三名候選人；錄用者下週到職並適應一週。能力訓練成效因人而異。改善計畫持續四週。

跨週企劃持續占一個名額，只收初次費用；取消不退還投入。座位不夠時可付費擴張。

## 音效（新版）

主畫面「音效開／關」與背景音樂獨立。工作中會有低音量鍵盤與包裝動作聲；客人訊息、一般事件、重大新聞、決策及週結算有不同提示音。預設關閉；首次開啟後會記住設定。音效以瀏覽器 Web Audio API 即時合成，不需下載額外音效檔。

## 美術

10 張以內建 image_gen 生成的精品風格插圖，涵蓋人物、商品、行銷、培訓、商機、危機與併購。不同卡牌共用相應主題圖。人物為虛構藝術形象，不是本人肖像。提示詞收錄於 docs/art-prompts.json；repo 內為壓縮後的 WebP 版本。

## 存檔

本機瀏覽器自動儲存。經營報告頁可匯出、載入 JSON。舊版遊戲及其存檔不受影響。換瀏覽器或清除網站資料前請匯出。

## 版本範圍

這是可由第一關玩到第七關的本機測試版本。public/tzgro-office-growth-preview.html 可直接預覽擴建後兩層辦公室的示意編制；不影響正式遊戲存檔。事件對話為規則與預寫文本，尚未接入 AI API；不是自由對話。人物會依角色在工位、報告交接點與出貨架之間自主移動，忙碌時支援包貨，並有短暫休息；角色圖卡使用生成插圖。

成本以商品 8–10%、基準營運 30%、基礎行銷 10% 為起點；額外員工薪資、場地、行動及事件另外列計。收入、風險機率、解鎖時間及過關目標為遊戲參數，尚未做歷史營收校準，不保證 5% 誤差。公司關卡年份是遊戲安排；史實參考來源可在經營報告查看。

AI 導入技能、自由生成專案、全直播團隊挖角等後續擴充尚未納入本版。現有人事事件及工作紀錄已可影響決策。

## 看懂因果、收成泡泡（2026-10-21 新增）

- **3D 辦公室名牌**：顯示「名字｜這週負責的卡」；沒派任務的同事顯示「日常工作」；超載時名牌變紅、標「超載！」。辦公室下方員工列也列出各自負責的卡。
- **員工頭上的泡泡**：工作時間內，同事頭上會不定時冒泡，6 秒內點了才收成，沒點不扣分。泡泡種類看他這週負責什麼：
  - 💬 客人詢問（行銷類卡、或沒派任務的日常客服）：成交 1 筆，營收 +NT$6,500
  - ⭐ 好評（商品類卡）：口碑 +0.3
  - 💡 靈感（人員、管理類卡）：這位同事該卡對應的能力 +0.5
  - 有派任務的同事冒泡機率較高；暫停、事件或對話時泡泡停住不消失。
- **週末「本週為什麼是這個數字」**：逐項列出每張卡由誰負責、約帶來多少營收；日常業務與卡牌搭配各占多少；每個事件誰回報、你選了什麼、營收／現金／口碑／士氣實際變多少；你點收的泡泡帶來什麼。每週回顧也看得到。
