# TZGRO 珠寶人生｜遊戲說明

網址：<https://vitokok-lab.github.io/GEMBOSS-GAME/>　本機：`npm run dev` 後開 <http://127.0.0.1:8766/>

## 目標

從 2019 年經營彩色寶石公司到 2025 年底。成功上市需要：完成「上市申請」、最後一年營收 2.5 億以上、有獲利、士氣 45 以上。一局約 30–45 分鐘。

## 兩種提早結束

- 對手拿下六成市場（品類被定義）
- 現金低於零（破產）

## 每個月發生什麼

客人依序走過：觸及 → 詢問 → 成交 → 熟客；熟客的口碑再帶來新的觸及。對手同時在搶還沒被拿下的客人。訂單超過出貨產能時，口碑和士氣會下滑。一個月約 20 秒，可暫停、2x、4x；有事件時自動暫停。

## 你能做的事

- 點金色泡泡收成口碑點，用點數＋現金解鎖能力樹（商品、通路、組織，部分依年份開放）
- 調整每月廣告預算
- 招募、資遣、擴張辦公室（座位依年份開放）
- 每年初指派商品、通路、組織三位負責人
- 處理事件與真實新聞：沒有標準答案，看當下的產能、現金、口碑；能查證就先查證

## 開局與難度

標準創業（500 萬、3 人）、網紅起家（200 萬、口碑強、出貨弱）、代工轉品牌（1,000 萬、5 人、品牌弱）；輕鬆／標準／困難。

## 新手與老手

- **新手**（預設）：畫面一步一步打開。一開始只有市場、日期、現金和「開始營業」；每學會一件事才出現下一個功能，提示卡會寫明要點哪個按鈕。2019 年負責人照預設，2020 年起才自己指派。
- **老手**：完整畫面直接打開，不教學。教學走完或按「不用教了」後，下次預設老手。
- 頁首「玩法」可隨時重看規則。

## 結局診斷

一局結束會列出七項指標（現金跑道最低點、獲客成本 vs 客人價值、產能超載月數、採購前查證、對手最高市占、年度目標、事件判斷），每項附一句經營原則。
